Set up EmailJS

  1. Sign up at EmailJS and add an Email Service for the inbox where you want to receive inquiries.
  2. Create an Email Template. Set Reply-To to {{from_email}} and include {{from_name}} and {{message}} in the subject/body. Set the recipient to your inbox in EmailJS.
  3. In EmailJS, copy your Service ID, Template ID, and Public Key. Paste each into its matching field below and press Save Changes.
  4. Open the public contact form and send a test. Check the inbox and spam folder. If sending is not configured, the visitor is prompted to use their email app.

Only use the EmailJS Public Key here. Never put an EmailJS Private Key or email account password in this page.
